合规博士隐私政策

生效日期：2026 年 11 月 10 日

发布者：maoyuan wen（Microsoft Store 中显示的发布者）

联系方式：alphameta@outlook.com

本政策说明合规博士桌面应用会处理哪些信息、用在哪里、发给谁，以及你可以怎样控制这些信息。

一、我们处理的信息

  1. 1. 账号信息：你用灵阙平台账号登录。登录记录包含登录凭证、账号邮箱、显示名称、账号编号以及所属组织和公司，由操作系统自带的加密功能加密后保存在本机，不会保存成可以直接阅读的文件。
  2. 2. 对话内容：你输入的问题、应用生成的回答，以及助手在对话中读取的文件内容。你附加的文件会在本机保存一份只读副本，供助手读取。除了你附加的文件和任务工作区里的文件，助手还能读取你当前电脑登录用户能打开的其他文件，例如桌面、文档和下载文件夹中的文件；目前没有关闭这项读取的开关。助手还可以检索这个工作区以往的对话记录。读取和检索到的内容都会成为对话内容的一部分。
  3. 3. 交付文件：交付的文件保存在当前任务的工作区文件夹，默认是系统「文档」文件夹下的「合规博士/default-workspace」，也可以是你在「新建项目」时选择的文件夹。
  4. 4. 本机记录：对话记录、附加文件的只读副本、你添加的技能和连接器开关，保存在电脑个人文件夹下的隐藏文件夹 .hegui-drc 中。加密的登录记录、上次退出登录的记录（不含账号信息）、界面设置、快捷键、尚未发送的输入草稿和应用内置网页组件的缓存，保存在应用数据文件夹的 hegui-drc 目录中（macOS 上是 ~/Library/Application Support/hegui-drc）。应用出现严重错误时写下的错误报告（保留最近 10 份），在 Windows 上也保存在这个目录中，在 macOS 上保存在 ~/Library/Logs/hegui-drc。起草过程中的中间文件保存在系统临时文件夹。

二、信息会发往哪里

  1. 1. 灵阙平台：登录前，应用会检查灵阙平台的登录服务是否可用。登录、退出登录，以及每一次提问时的对话内容（包括助手读取的文件内容），都会连同你的登录凭证发送到灵阙平台（lingque.app）。应用只通过灵阙平台调用大模型，不直接连接任何模型厂商。默认情况下，灵阙平台只把对话内容交给由国内厂商提供、并在中国境内处理的模型，目前是火山方舟（字节跳动）提供的豆包模型。企业管理员可以在企业管理后台启用其他模型，启用之前，后台会先显示跨境提示，写明对话内容的最终接收方、处理地区和用途。这些模型可能在中国境外处理，你选用它们时，对话内容会发给跨境提示中写明的接收方。你在应用中能选择的模型列表，就是你所在企业启用的模型；企业没有另行设置时，就是上面的默认模型。灵阙平台如何保存与处理对话内容，请查阅灵阙平台的隐私政策。
  2. 2. 合规知识图谱：查询合规知识图谱时，应用会把查询内容发送到合规网知识图谱服务（hegui.io）。
  3. 3. 联网搜索：本版本不提供联网搜索，应用不会把你的搜索词发送给任何搜索引擎。
  4. 4. 网页读取：本版本关闭了网页读取功能。你给出网址时，助手会说明这一点，并可以改用合规知识图谱。
  5. 5. 辅助命令：为了生成文档，助手会在你的电脑上运行辅助命令。这些命令在无网络的环境中运行，不能连接互联网或局域网；只能改动当前任务工作区和草稿文件夹中的文件，以及 Windows 为辅助命令单独保留的应用数据文件夹；该文件夹中的临时文件会在同类辅助命令全部结束后清空，其余文件会一直保留。在 Windows 上，它们还只能读取工作区、草稿文件夹、应用自带的运行环境以及系统和程序文件夹，读不到「文档」「桌面」「下载」等个人文件夹。某条命令确需联网时，助手会先征求你的同意，经你确认后这一条命令才会联网运行。
  6. 6. 其他连接器：「合规工具箱」（识别图片和扫描件中的文字，计算工作日与期限）和「时间工具」默认开启，全部在你的电脑上完成，不联网。其余连接器默认关闭；开启前，确认卡片会写明它的用途和访问范围。
  7. 7. 举报邮件：当你选择「报告此回答」，应用会打开你电脑上的邮件程序，填好发往产品支持邮箱的内容，是否发送由你决定。应用本身不会为举报发起网络请求。
  8. 8. 定时任务：你或助手创建的定时任务会按设定的时间自动运行，每次运行都会像一次提问那样把任务内容发送到灵阙平台。在 Windows 上，关闭窗口后应用仍在系统托盘中运行；在 macOS 上，关闭窗口只是隐藏窗口，应用继续运行。两种情况下定时任务都照常执行；退出应用后不再运行。

除上述情况外，应用本身不会把你的信息发送给其他方。应用不包含使用统计或行为分析，也不会上传错误报告。

三、你的控制权

  1. 1. 你可以随时退出登录。退出登录会立即删除本机保存的加密登录记录，留下一条不含账号信息的退出记录，并在后台通知灵阙平台结束这次登录；对话记录、尚未发送的草稿、缓存和工作区中的文件不会因此删除。应用内不提供账号管理入口，修改或注销账号请联系灵阙平台。
  2. 2. 你可以在「专家·技能·连接器」的「已安装」列表中，用每一项右侧的开关停用「灵阙连接器」或其他连接器。助手读取本机文件和运行辅助命令是内置功能，不受这些开关控制。
  3. 3. 删除 .hegui-drc 文件夹会清除对话记录、附加文件的副本、你添加的技能和连接器开关。在 Windows 上，卸载应用会删除应用数据文件夹中的内容，但不会删除 .hegui-drc 文件夹、Windows 为辅助命令单独保留的应用数据文件夹、工作区中的交付文件和系统临时文件夹中的起草文件，这些需要你自行删除。在 macOS 上，把应用移到废纸篓即可删除应用；应用数据文件夹（~/Library/Application Support/hegui-drc）、错误报告文件夹（~/Library/Logs/hegui-drc）、.hegui-drc 文件夹、工作区中的交付文件和系统临时文件夹中的起草文件都会保留，需要你自行删除。
  4. 4. 你可以在「自动化」页面停用定时任务。停用会删除这个任务，已经生成的报告仍然保留。
  5. 5. 关于灵阙平台保存的数据，请按灵阙平台隐私政策提出查询、更正或删除请求。

四、安全

登录记录由操作系统自带的加密功能加密。对话记录、附加文件的副本、草稿、错误报告和其他本机文件没有加密，能使用你电脑用户账户的人或程序都可以读取。应用连接的灵阙平台、知识图谱和搜索服务都使用 HTTPS 加密通信；安装的应用不能改为连接其他服务地址。

对话记录按灵阙账号分开显示：每个新任务和新添加的项目文件夹会在 .hegui-drc 文件夹的 session-owners.json 中记下创建它的账号编号。任务列表、搜索和项目文件夹列表只显示当前登录账号的任务和文件夹，其他账号的任务在应用里也打不开；默认工作区对所有账号显示，几个账号都添加过的同一个项目文件夹对这几个账号都显示，但其中只显示当前账号的任务。未登录时不显示任何任务记录。定时任务只在创建它的账号登录时运行：其他账号登录或没有登录时到期的运行不会执行，也不会在之后补跑，该账号再次登录后会看到它已错过；这个任务发出的确认卡片也只显示给该账号。更新到这个版本之前的任务和文件夹，归更新后第一个登录的账号。这只是这台电脑上的显示筛选，不是加密：对话记录文件没有按账号加密或分开存放，能使用你电脑用户账户的人或程序仍然可以读取所有账号的对话记录。

五、生成式人工智能

回答由大模型实时生成，可能存在错误。如果你看到不当内容，请在该回答下选择「报告此回答」，或发送邮件到上面的联系方式，我们会处理每一份报告。

六、政策更新

应用的功能变化影响信息处理方式时，我们会更新本政策并修改生效日期。
